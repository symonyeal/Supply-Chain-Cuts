### W1. A residual estimator, and the importance-sampling defect

**Why.** The upper bound U = L + P(more than three losses) is 1 at every Li-ion headline (P(N > 3) =
0.915, since Σp ≈ 7.9), so the only informative number is an estimate. On the joint network at α = 10%
the importance-sampling estimate (0.685, interval 0.646–0.724) fell below the exact L (0.716) while
crude Monte Carlo gave 0.723 ± 0.003: tilting toward cut nodes inflates variance when failure is common.

**Do.** Implement in `chokepoint/risk.py` the control-variate estimator
P̂ = L + mean(1{fail(Z)} − 1{Z contains an enumerated cut}), Z drawn from the scenario law. Its variance
comes only from the residual event (failing states that contain no cut of support ≤ k, which by
Proposition 3 have support > k). Optionally add defensive mixture IS (proposal = (1 − λ) tilted + λ
original) for the rare regime. Derive the estimator and its standard error in `docs/MODEL.md` first.

**Done when** (a) a test checks the estimator against the exact probability on the hand-enumerated
toy of `tests/test_risk.py` and against crude MC on a random network; (b) all three bundles report it;
(c) every estimate is reported with L, and the joint α = 10% case reads consistently with L; (d)
FINDINGS §1–2, VALIDATION (bracket row), README and the site use it, and say which estimator each
number comes from.
